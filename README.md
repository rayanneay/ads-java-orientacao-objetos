# ADS — Java: Orientação a Objetos

## Sobre o projeto

Este repositório reúne exercícios e atividades desenvolvidos na disciplina de Orientação a Objetos do curso de Análise e Desenvolvimento de Sistemas (ADS).

O foco atual é praticar a lógica de programação em Java por meio de problemas simples e progressivos.

## Conteúdos praticados

- Entrada de dados com `Scanner`
- Variáveis e operações matemáticas
- Estruturas condicionais: `if`, `else if` e `else`
- Estrutura de seleção: `switch`
- Estruturas de repetição: `for` e `do...while`
- Criação de menus e validações básicas

## Organização

- `AtividadeUmAulaDois/`: atividades da aula 2
- `ExerciciosAulaDois/`: exercícios práticos da aula 2
- Cada arquivo `.java` contém a solução de uma atividade ou exercício.

## Como executar

1. Abra o projeto no VS Code.
2. Abra o arquivo `.java` desejado.
3. Clique em **Run** acima do método `main` ou pressione `F5` para executar no modo de depuração.
